note bottom of sharedDb
**Единая БД с изолированными схемами**
• Физически — PostgreSQL + ClickHouse
• Логически — отдельные schemas по модулям
• Нет прямых cross-schema JOIN
• Все межмодульные взаимодействия — через Facade

' ====================== Легенда ======================
legend right
|= Ключевые принципы модульного монолита |
| Модули общаются только через **Facade** (in-memory) |
| Каждый модуль владеет своей **database schema** |
| Запрещён прямой доступ к таблицам чужого модуля |
| Единый процесс и деплой (один Docker-образ) |
| ACID-транзакции могут охватывать несколько модулей |
endlegend
